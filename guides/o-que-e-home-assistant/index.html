Introdução

Já imaginaste ter uma casa que sabe quando chegas, acende as luzes no tom certo, ajusta a temperatura, fecha os estores, e até te avisa se há uma fuga de água? Parece ficção científica, mas é mais simples do que pensas.

O problema é que o mercado de casa inteligente está cheio de sistemas fechados. Tens uma lâmpada Xiaomi que só funciona na app Mi Home. Uma tomada Tuya que só obedece à app Smart Life. Um sensor Aqara que precisa do seu próprio hub. Resultado: tens 5 apps no telemóvel, nenhum dispositivo fala com o outro, e a "casa inteligente" é tudo menos inteligente.

É aqui que entra o Home Assistant (HA).

!Interface Lovelace com dashboards de clima, temperatura, controlos rápidos e sensores Interface Lovelace — clima, temperatura, controlos rápidos, sensores de porta, câmaras e energia.

O que é o Home Assistant?

O Home Assistant é um software open-source que funciona como o sistema operativo da tua casa inteligente. Pensa nele como um hub universal — uma plataforma que junta todos os teus dispositivos, independentemente da marca, e permite controlá-los todos a partir de um único sítio.

As promessas do HA

  • Privacidade primeiro: tudo funciona localmente na tua rede. Sem nuvens, sem empresas a recolher os teus dados
  • Qualquer dispositivo: mais de 2000 integrações — Xiaomi, Tuya, Philips Hue, Sonoff, Shelly, Zigbee, Z-Wave, WiFi, Bluetooth...
  • Sem mensalidades: é 100% gratuito
  • Controlo total: fazes o que queres, como queres

Open-source significa o quê?

O código do Home Assistant é público. Isto significa que não há portas traseiras escondidas, não há publicidade nem venda de dados, milhares de programadores contribuem para o tornar melhor todos os dias, e é atualizado regularmente (nova versão todos os meses).

O problema das nuvens

Quando usas Google Home ou Alexa, cada comando de luz segue este caminho:

Telemóvel → Router → Servidores Google/EUA → Router → Lâmpada

Se a internet cair, o interruptor inteligente é só um pedaço de plástico. Com o Home Assistant, tudo fica dentro de casa:

Telemóvel → Router → Raspberry Pi (com HA) → Lâmpada
Sem internet? Funciona na mesma.

O que podes fazer com o Home Assistant?

Controlo de iluminação

  • Acender luzes automaticamente ao anoitecer
  • Simular presença quando estás de férias
  • Criar "cenas" — um botão "Cinema" desliga luzes, fecha estores e liga a TV
  • Temperatura de cor automática (fria de manhã, quente à noite)

Clima e conforto

  • Termostato inteligente que aprende a tua rotina
  • Ventilação automática baseada na humidade
  • Aquecimento ligado quando a temperatura desce

Segurança

  • Câmaras que gravam só com movimento
  • Sensor de porta que notifica se alguém abriu quando não estás
  • Detetor de fumo que desliga o gás automaticamente
  • Alarme que liga quando sais

Energia

  • Monitorização de consumo em tempo real
  • Alertas se o consumo ultrapassar um limite
  • Painel solar + bateria: gerir carga e uso
  • Comparação de gastos dia-a-dia

Automatizações do dia-a-dia

  • "Bom dia": estores abrem, café liga, rádio liga
  • "Saí de casa": tudo desliga, alarme liga, aspirador começa
  • "Dormir": luzes desvanecem, portas trancam, temperatura baixa

Como funciona o Home Assistant?

Arquitetura simplificada

┌─────────────────────────────────────────┐
│            Home Assistant                │
│  ┌─────────┐ ┌─────────┐ ┌──────────┐   │
│  │Integrações│ │Automações│ │Dashboards│   │
│  │  Xiaomi  │ │ Se...   │ │  Visão   │   │
│  │  Tuya    │ │ Então... │ │  Quartos │   │
│  │  Zigbee  │ │ Scripts  │ │ Energia  │   │
│  └────┬────┘ └─────────┘ └──────────┘   │
└───────┼──────────────────────────────────┘
        ▼
┌─────────────────────────────────────────┐
│        Dispositivos Físicos             │
│  Lâmpadas │ Sensores │ Câmaras │ TVs    │
└─────────────────────────────────────────┘
  1. Integrações — ligam o HA aos teus dispositivos
  2. Entidades — cada sensor, luz, interruptor, etc. é uma "entidade"
  3. Automações — regras do tipo "se [X], então [Y]"
  4. Dashboards — os ecrãs que vês no telemóvel, tablet ou PC

Onde corre o HA?

O Home Assistant é um servidor que precisa de estar ligado 24/7:

  • Raspberry Pi (recomendado) — ~50€, consome 5W
  • Um PC velho em casa
  • Um servidor NAS (Synology, QNAP)
  • Um servidor dedicado (Intel NUC, HP ProDesk)

Conclusão

O Home Assistant é a plataforma de casa inteligente mais poderosa que existe. Gratuita, privada, open-source, funciona com praticamente qualquer dispositivo.

Sim, no início parece intimidante. Mas prometo-te: se eu consegui, tu também consegues. E vais aprender tudo aqui, passo a passo.

Perguntas Frequentes

Home Assistant é gratuito?
Sim, o Home Assistant é open source e 100% gratuito. O único custo é o hardware (Raspberry Pi ~50-100€).
Preciso de saber programar?
Não. As versões recentes têm interface visual para criar automações sem código. YAML ainda existe para configurações avançadas, mas não é obrigatório.
Funciona sem internet?
Sim! Essa é a maior vantagem. Tudo funciona localmente na tua rede. Se a internet cair, a casa continua inteligente.
Quantos dispositivos posso ligar?
Centenas. O HA tem integração com mais de 2000 marcas. Podes ligar luzes, sensores, câmaras, tomadas, estores, e muito mais.
